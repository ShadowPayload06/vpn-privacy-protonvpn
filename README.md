ProtonVPN Workflow: Privacy Validation

This repository documents a step-by-step VPN validation workflow using ProtonVPN. It includes screenshots, `.txt` logs, and encryption research to demonstrate secure browsing, IP masking, and traffic protection. The structure is designed for reproducibility, audit-readiness, and internship-grade presentation.

🎯 Objectives

- Connect to a VPN server and validate connection
- Verify IP address change and HTTPS encryption
- Compare browsing speed before and after VPN
- Research ProtonVPN’s encryption and privacy features
- Summarize VPN benefits and limitations

✅ Steps Completed

1. Connected to ProtonVPN (Netherlands & India servers)
2. Verified IP address change via [whatismyipaddress.com](https://whatismyipaddress.com)
3. Confirmed HTTPS encryption via [wikipedia.org](https://wikipedia.org)
4. Compared browsing speed and IP after disconnect
5. Researched ProtonVPN’s encryption protocols and privacy infrastructure
6. Summarized VPN benefits and limitations

🔍 Key Findings

- ProtonVPN uses AES-256, WireGuard, and Secure Core routing
- IP address successfully masked and reverted post-VPN
- HTTPS traffic confirmed encrypted via TLS 1.3
- No logs policy enforced under Swiss jurisdiction
- VPN improves privacy but may reduce speed and require trust in provider
